BMI Calculator

Description

The BMI Calculator is a Python-based application developed as part of the Oasis Infobyte Python Programming Internship.

It calculates Body Mass Index (BMI) using the user's weight and height. It displays the BMI value, health category, and a personalized message through a colorful terminal interface.

Objectives

- To calculate BMI accurately using weight and height.
- To identify BMI categories.
- To provide a simple and user-friendly interface.
- To handle invalid inputs.

Features

- User name input
- Weight and height input
- Automatic BMI calculation
- Four BMI categories
- Colorful terminal output using Colorama
- BMI visual bar
- Input validation and error handling
- Option to calculate again

BMI Formula

BMI = Weight (kg) / Height (m)²

Technologies Used

- Python 3
- Pydroid 3
- Colorama Library

How to Run

1. Install Pydroid 3.
2. Install Colorama using "pip install colorama".
3. Open "bmi_calculator.py".
4. Run the program.
5. Enter your name, weight, and height.
